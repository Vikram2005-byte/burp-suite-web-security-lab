# Pre-Engagement Checklist

Complete this checklist before security testing begins.

- [ ] Written authorization has been confirmed.
- [ ] In-scope domains, IP addresses, applications, and environments are recorded.
- [ ] Explicit exclusions are understood.
- [ ] Allowed and prohibited techniques are documented.
- [ ] Test dates, times, and rate limits are agreed.
- [ ] Test accounts are provided through an approved secure channel.
- [ ] Emergency contact and stop-work procedure are known.
- [ ] Data handling, evidence storage, and retention rules are understood.
- [ ] Backup and recovery expectations are known where relevant.
- [ ] Reporting format and responsible disclosure channel are agreed.
- [ ] Browser and Burp project contain no unrelated personal traffic.
- [ ] Evidence will be sanitized before it is shared or committed.
