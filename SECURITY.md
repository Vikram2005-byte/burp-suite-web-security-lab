# Security Policy

This repository is an educational collection of notes and templates, not a production application.

## Reporting a concern about this repository

For a potentially sensitive issue involving this repository, avoid publishing secrets, private target details, personal information, or exploit evidence in a public issue. Contact the repository maintainer privately through GitHub to coordinate disclosure.

## Vulnerability research

- Test only systems you own or have explicit authorization to assess.
- Use the PortSwigger Web Security Academy or isolated local labs for practice.
- Follow the target owner's rules of engagement and responsible disclosure process.
- Do not publish third-party credentials, session tokens, personal data, or confidential findings.
- Do not include licensed software, license-bypass tools, or unknown binaries in this repository.

## Scope

This policy applies to content in this repository. It does not grant authorization to test PortSwigger, GitHub, or any other system.
