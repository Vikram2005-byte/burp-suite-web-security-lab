# Burp Suite Web Security Lab

This repository is my workspace for learning web application security with Burp Suite. It keeps setup notes, testing checklists, lab write-ups, and a reusable report template together.

## Getting started

1. Download Burp Suite from the [official PortSwigger page](https://portswigger.net/burp/downloads).
2. Start with the free [Web Security Academy](https://portswigger.net/web-security) labs.
3. Follow the [official getting-started guide](https://portswigger.net/burp/documentation/desktop/getting-started) to configure a dedicated browser and proxy.
4. Keep practice to the Academy or a local lab until you have clear permission to test another system.

Burp Suite Professional requires a valid licence or trial. This repository links to the official installer; it does not distribute the software or any licence-bypass tools.

## What you'll find here

- `docs/setup.md` — setup and troubleshooting notes
- `docs/testing-methodology.md` — a repeatable workflow for authorized testing
- `checklists/pre-engagement.md` — things to confirm before starting an assessment
- `notes/README.md` — suggested topics for learning notes
- `reports/TEMPLATE.md` — a template for recording a finding clearly

## A few ground rules

Only test systems you own or have explicit permission to assess. Keep credentials, session cookies, personal information, and private engagement details out of commits. Use sanitized evidence and include remediation advice with each finding.

This is an independent learning project, not an official PortSwigger repository. For current tool instructions, use the [Burp Suite documentation](https://portswigger.net/burp/documentation).
